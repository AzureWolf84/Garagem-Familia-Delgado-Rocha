GARAGEM DA FAMÍLIA DELGADO ROCHA - versão 1.6.8 (GitHub Pages)

1. Crie um repositório público no GitHub (ex.: garagem).
2. Envie TODO o conteúdo desta pasta para a raiz do repositório
   (index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, icon-maskable-512.png, .nojekyll).
3. Em Settings > Pages, selecione "Deploy from a branch", branch main, pasta / (root).
4. Aguarde 1 a 2 minutos. O endereço será https://SEUUSUARIO.github.io/garagem/
5. Para conferir a versão, o rodapé deve mostrar "Edição 1.6.8".
6. Para instalar no celular: abra o endereço no Chrome e use Menu (⋮) > Instalar aplicativo.

Os dados ficam salvos no navegador de cada aparelho. Faça backup em "Backup e dados".
