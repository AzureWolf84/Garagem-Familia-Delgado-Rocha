GARAGEM DA FAMÍLIA DELGADO ROCHA — PWA 1.1.1

CONTEÚDO
- index.html: aplicativo atualizado, com integração OneDrive removida e navegação mobile reformulada.
- manifest.webmanifest, sw.js e ícones: instalação PWA e cache offline.

ATUALIZAÇÃO
1. Publique/substitua TODOS os arquivos deste pacote no mesmo endereço HTTPS da versão anterior.
2. Abra o aplicativo conectado à internet para que o service worker instale o novo cache 1.1.1.
3. Antes de migrar de endereço ou limpar dados do navegador, exporte um backup JSON local.
4. Os dados existentes permanecem no armazenamento local do navegador; esta atualização não limpa registros, veículos, documentos ou anexos.

MUDANÇAS DA VERSÃO 1.1.1
- Removida integralmente a integração OneDrive/Microsoft Entra/MSAL/Microsoft Graph, incluindo telas, configuração e chamadas externas.
- Preservados backup completo JSON, restauração validada, exportação CSV, análise de armazenamento e verificação de integridade.
- Reformulada a navegação mobile: quatro destinos principais e painel "Mais opções" para os demais módulos, sem ocultar Odômetros, Documentos, Abastecimentos, Despesas, Relatórios, Histórico, Backup ou Configurações.
- Reorganizados cabeçalho, títulos, cartões, formulários, botões, tabelas e modal para telas estreitas.
- Mantida a paleta cromática existente do aplicativo.
- Cache do service worker atualizado para 1.1.1.

DADOS E BACKUP
- Os dados permanecem armazenados localmente no navegador e no aparelho em que foram cadastrados.
- O backup JSON inclui os registros e arquivos anexados suportados pelo aplicativo.
- A restauração valida o arquivo e apresenta um resumo antes de substituir os dados locais.
- O backup não é protegido por senha. Guarde o arquivo em local confiável.
- A capacidade de armazenamento depende do navegador e do dispositivo. Faça backups periódicos.

LIMITAÇÕES
- Esta edição não oferece sincronização entre aparelhos nem backup em nuvem automático.
- PWA completo e service worker exigem HTTPS (ou localhost em desenvolvimento). Abrir index.html via file:// não permite instalação PWA completa.
